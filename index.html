02 — Selected work

01

LedgerLoop

Explainable payment reconciliation

A workspace for a small online seller that lines up orders, gateway payments, and bank-statement lines, and explains each suggested match before it is treated as confirmed.

The rules engine auto-confirms exact references and settlement nets. Nickname, split-transfer, and instalment matches stay suggestions. Duplicates, missing refund debits, unpaid orders, and fees above the contract are flagged. An exception inbox tracks owner, status, notes, and follow-up drafts, with an audit log of confirmations, rejections, and CSV imports. One login keeps a separate set of books for each store.

JavaScript · React · Node.js · Express · MongoDB · Docker

BookVault

Personal library, MERN

A full-stack book manager with JWT authentication and bcrypt password hashing. Seven REST endpoints cover auth, book management, and protected routes. Two MongoDB collections, Users and Books, keep data scoped to the signed-in person.

The dashboard tracks reading status and filters by tag. Four reusable React components span login, signup, and the dashboard, with Context API for shared state and Axios for requests. Deployed on Vercel, Render, and MongoDB Atlas.
